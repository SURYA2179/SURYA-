# Simulation Evidence

This project is configured to produce reproducible evidence instead of claiming results from source inspection alone.

## Where to find evidence

1. Open the repository's **Actions** tab.
2. Select the **Traffic-light RTL simulation** workflow.
3. Open a completed run and inspect the job log.
4. Download the traffic-light-controller-simulation-evidence artifact. It contains:
   - simulation.log — compiler/run output and self-checking PASS summary.
   - traffic_light_controller.vcd — waveform data for GTKWave.

## What constitutes a pass

A passing run must compile successfully, exit with status zero, display the final PASS summary, and upload both the simulator log and waveform. A failed assertion or compile error fails the workflow.

## Evidence integrity

A commit that only adds source code is not evidence that simulation passed. After the first completed workflow run, this document can be supplemented with a link to the exact Actions run and its commit SHA. Until a run is completed, treat the simulation evidence as pending rather than verified.

## Local evidence

When running locally, save the full terminal output to a file and retain the waveform generated by the testbench. Record the simulator version, command, date, and commit SHA so another reviewer can reproduce it.
